# Home

App personal: Hoy, Finanzas (con clave), Agenda (Google Calendar), Wellness y Pendientes.
Se sincroniza con la hoja FIN y con una hoja propia "HOME · datos de la app" en Google Drive.

- Web: https://jgvillota3.github.io
- Android: descarga `Home.apk` desde la sección Releases (se compila sola con GitHub Actions).
- Modo demo (sin Google): https://jgvillota3.github.io/?demo
